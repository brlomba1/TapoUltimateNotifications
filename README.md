Description:
Ultimate rich notifications for Tapo cameras in Home Assistant

Features:
-Rich Notification snapshot
-Direct Link - clicking the notification opens to the camera live feed
-Toggle on siren from notification
-Toggle on privacy from notification

Requirements
-You need to get your tapo device ID, link is provided inside blueprint on how to do it. Save the output for future use.
-Developed for android only at the moment. 

Any additional features please let me know.
